# Contribution Guidelines

Please see the comprehensive [CONTRIBUTING.md](CONTRIBUTING.md) file for development setup, architecture overview, code standards, test execution, and pull request guidelines.

## Quick Reference

1. **Setup**:
   ```bash
   pip install -e ".[dev]"
   ```
2. **Run Tests**:
   ```bash
   pytest tests/
   ```
3. **Branching**:
   ```bash
   git checkout -b feat/your-feature
   ```
4. **License**:
   All contributions are provided under the [MIT License](LICENSE).
